# RnS KnightSchool

> **Ruben and Sammy's Knight School** - A visual-learning Chess app for kids 5+

## Vision

A chess learning app built on the "Anti-Stockfish" philosophy: show less, not more. No cluttered analysis arrows. No intimidating engine evaluations. Just color-coded visual hints that teach chess the same way kids learn - through patterns, not lectures.

**Direct port of the [RnS SuDoCoach](https://rns-sudocoach.vercel.app) teaching approach.**

## Target Audience

- **Ruby (5)** - Still learning how pieces move
- **Sammy (older)** - Ready for tactical patterns
- Any kid who's been overwhelmed by traditional chess apps

## Core Features

- **Full games vs Training Wheels AI** - Opponent creates learning opportunities
- **Color-coded teaching** - Green = safe, Red = danger, Yellow = tactical pattern
- **"Where can I go?"** - Tap any piece to see legal moves
- **Tactical celebration** - "Your knight is causing mischief!" when forks happen
- **No pressure** - No timers, no ELO, no judgment

## Tech Stack

- Next.js 16+ (same as SuDoCoach)
- chess.js (game rules)
- stockfish.wasm (AI opponent)
- Tailwind CSS + shadcn/ui
- Zustand (state management)
